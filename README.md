Lure
Hello guys, this is Lure! I make this small 3D explore and puzzle game in Unity 6.

Main mission is very simple: just roam around the map, search for hidden loot chests, and collect 5 scrap metal pieces. Then use them to fix the broken radio tower.

Things I make in this project:

Full working inventory and hotbar.

Loot chests you can actually open and take items from.

Scuba goggles you can wear so underwater vision become clear.

My own UI to show button prompt and repair progress.

Controls:

WASD - For moving

Mouse - Look here and there

E - Interact (open chest, pick item, fix tower)

Scroll Wheel (or 1-7) - Change items in hotbar

Left Click - Use the item you are holding

How to play:
No need downloading anything! I make it WebGL so it play directly in your browser. Just play it on my itch.io page here: [Link]

(One tip: please press the fullscreen button in bottom corner before playing!)
